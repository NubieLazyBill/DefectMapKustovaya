### Функциональная проверка без GUI (пройдена на ALT)

Скрипт `packaging/linux/FunctionalCheck.java` (компилируется в ВМ против готового JAR)
проверяет то, что не покрывает `--selftest`:

```
[1/3. База данных]   [OK] 186 записей; дефект записан, обновлён, удалён
[2/3. Экспорт Excel] [OK] xlsx 4705 байт, читается обратно (6 строк)
[3/3. Печать]        [OK] задание ушло на «Cups-PDF», PDF 133 КБ создан
РЕЗУЛЬТАТ: OK
```

Запуск на ALT:

```bash
javac -encoding UTF-8 -cp build/libs/DefectMap.jar -d /tmp/fc packaging/linux/FunctionalCheck.java
java -Ddefectmap.home="$HOME/dm-data" \
     -cp "build/libs/DefectMap.jar:/tmp/fc" FunctionalCheck
```

Особенность: Cups-PDF сохраняет PDF не в `~/PDF`, а на рабочий стол — проверка
ищет файл в `~/PDF`, `~/Desktop` и `~/Рабочий стол`.

### Исправлено за эту сессию

1. **Маркеры**: слой маркеров теперь совпадает с видимой областью схемы
   (`fitMarkerLayer()`), все пересчёты «пиксель ↔ процент» идут через
   `window.dmBoxRect()`. Старые данные пересчитываются `--fix-markers`
   (коэффициент 1.94, бэкап в `backups/marker-fix-*`).
2. **Зум**: в X11/VirtualBox колесо присылает фантомные события с `deltaY = 0`;
   они трактовались как прокрутка вниз и ломали приближение. Теперь такие события
   игнорируются, добавлен троттлинг 40 мс, направление настраивается
   `-Ddefectmap.wheelInvert=true`, есть `Ctrl + / Ctrl − / Ctrl 0` и пункты меню.
   `Ctrl 0` обрабатывается фильтром сцены, потому что WebView его перехватывает.

## Что осталось проверить (только через мышь в GUI)

1. «📋 Список оборудования» → 186 строк, двойной клик открывает карточку.
2. Добавить дефект в карточке → закрыть приложение → открыть → дефект сохранился.
3. «📊 Дефекты» → «Создать отчёт» → сохранить `.xlsx` (через диалог файла).
4. «🖨️ Печать» в окне отчёта → Cups-PDF → PDF в `~/PDF`.

Либо вместо ручных кликов: добавить команду `--functional` (проверка записи в БД,
Excel и печати без GUI) — потребуется один перенос папки `src` и пересборка.

## Окружение

* ВМ VirtualBox `ALT-Workstation-10.4`, экран 1024×768, раскладка переключается
  `Alt+Shift` (для моего клавиатурного ввода нужна английская).
* Проект: `~/Рабочий стол/DefectMap`, данные для запуска: `~/dm-data`.
* JDK 17 в системе (`javac 17.0.21`), `jpackage` внутри JDK (в PATH нет — это норма).
* `sudo` работает (`/etc/sudoers.d/wheel`), вход в sudo — пароль пользователя `admin`
  (тот, что задавали при установке; в документации и в репозитории он не хранится).
* Сборка пакетов: нужны `binutils`, `dpkg`, `fakeroot`, `xdg-utils`, `rpm-build` (установлены).
* `.rpm` через `jpackage` на ALT не поддерживается — не блокер (есть `.deb` и AppImage).
