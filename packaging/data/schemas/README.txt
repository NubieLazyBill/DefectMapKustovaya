Схемы подстанций (SVG)
=======================

Положите сюда файл схемы с именем  schema_<ключ>.svg
Ключи подстанций перечислены в файле substations.json (поле "key").

Примеры имён:
  schema_kustovaya.svg
  schema_mirnaya.svg

Файл schema.svg используется как общая заглушка, если отдельной схемы нет.

Поддерживается SVG, сохранённый из Microsoft Visio и браузеров.
Схема рисуется в WebView (WebKit), шрифты Arial / Times New Roman
автоматически заменяются на метрически совместимые аналоги
(Liberation Sans / Liberation Serif), если их нет в системе.

Где приложение ищет схемы (по порядку):
  1. каталог данных пользователя:
     Windows  — <папка_программы>\schemas
     Linux    — ~/.local/share/defectmap/schemas
  2. папка schemas рядом с программой (только чтение, поставка)
  3. ресурсы JAR (встроенные схемы)

Меню приложения: «Для разработчиков» → «Открыть папку schemas».
