Изображения оборудования
========================

Сюда можно положить свои фотографии оборудования (JPG/PNG).
Имя файла должно совпадать с тем, что указано в коде типа оборудования
(например: ТМ-35.jpg, ОПН-220.jpg, ВВБК-220(3 фазы).jpg).

Если файла нет — приложение берёт картинку из ресурсов JAR,
а при полном отсутствии рисует серую заглушку «Нет изображения».

Каталог данных пользователя:
  Windows  — <папка_программы>\images
  Linux    — ~/.local/share/defectmap/images

Меню приложения: «Для разработчиков» → «Открыть папку images».
